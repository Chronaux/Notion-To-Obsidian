# 0.5.6

- Исправлена двойная упаковка загрузок GitHub Actions: скачиваемый artifact `windows-x64-release.zip` теперь содержит готовый EXE, документацию и лицензии напрямую, без второго ZIP. GitHub Releases по-прежнему предлагает один обычный `NotionToObsidian_Windows_x64.zip` (собирается из проверенных файлов).
- В Win32 GUI выровнены по вертикали поля пути: область EDIT занимает высоту поля ввода вместо узкой строки.
- Уменьшено мерцание при обновлении прогресса: WM_PAINT не перерисовывает дочерние элементы (WS_CLIPCHILDREN), на каждом шаге анимации инвалидируется только область прогресс-бара.
- Кнопки выбора файлов/папки получили подсветку при наведении и курсор-указатель. Исправлен порядок отрисовки фокуса: контур больше не стирает значок папки. После закрытия диалога фокус возвращается окну.
- Обновлены проверки Windows-ресурсов, упаковки и документация.

# 0.5.5

- Нативное окно Win32 переработано по компактному тёмному макету: два поля выбора с кнопками-папками, лаконичная шапка, минимум рамок, единое основное действие и нижняя область статуса.
- Название окна Windows теперь «Notion → Obsidian» без номера версии; версия сохраняется в имени готового EXE, ресурсах, отчётах и документации.
- «Пропускать отсутствующие страницы» включено по умолчанию в GUI. CLI по-прежнему требует явный флаг `--skip-missing`; архивные страницы не определяются автоматически.
- «Конвертировать» переключается в «Отменить» на время работы, включая предварительную проверку ZIP; запрос отмены не блокирует окно.
- Нижний текстовый журнал заменён плавной полосой прогресса и краткими этапами. Конвертер передаёт реальные счётчики обработанных баз, страниц и сохранённых файлов; технические подробности остаются в `.notion-to-obsidian/migration-report.json`.
- Двойная буферизация отрисовки для уменьшения мерцания, обновлённая статическая проверка интерфейса.

# 0.5.4

- Исправлена диагностика ссылок на отдельные блоки Notion. Если Markdown & CSV не содержит позиции исходного блока, **текст страницы остаётся целым**, ссылка в Obsidian продолжает открывать локальную страницу, а исходный точный адрес и место использования записываются в `block_link_fallbacks` отчёта. Такие случаи больше не выдаются за потерю содержимого через `block_position_lost`.
- Если адрес ссылки указывает на заголовок, который однозначно присутствует в экспортированной Markdown-странице, конвертер сохраняет переход на этот заголовок.
- Отчёт и заметка «Начать здесь» объясняют разницу между переносом содержимого и ограничением точности перехода. Добавлены регрессионные тесты, включая повторяющиеся адреса и локальные ссылки.
- Изменения интерфейса и структуры «Базы данных» из 0.5.3 сохранены. Переносимая сборка Windows x64 и порядок публикации прежние.

# 0.5.3

- Базы Notion, их Markdown-таблицы, файлы `.base` и страницы записей перенесены в отдельный каталог верхнего уровня `Базы данных/`. Сохраняется реконструированная иерархия инструкций и вложенных подстраниц базы.
- Страницы инструкций, содержащие базы, остаются в своём разделе, а не перемещаются вместе с CSV. Таблицы продолжают отображаться непосредственно внутри таких страниц через блок `![[...#^notion-table]]`.
- Обновляются все внутренние ссылки, обратные ссылки на записи, пути в Bases и пути плагина копирования таблиц. Исходные Notion ID и Properties не меняются.
- Добавлены тесты отдельного расположения баз, сохранения ссылок и оглавлений, пустых баз и вложенных страниц. Обновлены документация и версия переносимого Windows x64 приложения.

# 0.5.2

- Страницы Notion с базой данных переносятся в папку соответствующей базы, а не остаются одноимёнными заметками уровнем выше. Восстановленные разделы, ссылки и записи сохраняются.
- Если название статьи совпадает с названием базы, исходная статья сохраняет `Название.md`, а отдельная читаемая Markdown-таблица получает название `Название — таблица.md`. Файл Bases остаётся рядом.
- Скруглённые элементы нативного тёмного интерфейса полностью закрашиваются перед отрисовкой: больше нет белых уголков на кнопках и флажке.
- Упрощены подписи, кнопки и сообщения; длинные URL и технические предупреждения не выводятся в основной журнал. Кнопка открытия папки появляется после успешного преобразования.
- Добавлены регрессионные тесты на структуру экспорта с одноимёнными базами и проверка оформления кнопок.

# 0.5.1

- В разделах больше не создаются синтетические заметки `Оглавление.md` из списка вложенных страниц. Сохранён механизм создания оглавления **внутри статьи** по её заголовкам. Реальные страницы Notion с названием «Оглавление» не затрагиваются.
- Настроена автоматическая проверка, Windows x64 сборка и выпуск готового ZIP через GitHub Actions. Перед публикацией проверяются Rust-тесты, ресурсы, Windows EXE, конвертация тестового экспорта и структура Vault.
- Постоянная ссылка на последний проверенный готовый Windows ZIP находится в README и ведёт в GitHub Releases. ZIP содержит EXE, инструкцию, лицензии и SHA-256. Триггеры: push в main и ручной запуск workflow.
- Сохранены изменения v0.5.0: нативная тёмная тема, иконка, плоский корень Vault и режим ручного пропуска отсутствующих страниц.

# 0.5.0 — подготовка исходников

- Переработан нативный интерфейс Win32: единая тёмная палитра, собственная отрисовка кнопок и переключателя, обновлённая компоновка, системная тёмная строка заголовка (при поддержке Windows).
- Добавлена уникальная иконка приложения (`assets/app.ico`, размеры 16–256 px). Значок включается в ресурс EXE и окно Windows.
- Версия обновлена в Cargo, метаданных Windows, названии окна, пути результата и отчётах.
- Для новой сборки требовались Rust и MinGW-w64. Механизм автоматической сборки и проверки добавлен в 0.5.1.

- Убрана вложенная папка `Vault/`: новая папка результата сама является хранилищем Obsidian. Заметки, Bases и `.obsidian` находятся в её корне.
- Отчёт, состояние импорта и вспомогательный текст перенесены в скрытую `.notion-to-obsidian/`, чтобы не загромождать дерево заметок.
- Добавлен ручной режим пропуска заглушек для отсутствующих страниц с распознанным Notion ID: ссылки сохраняются внешними, UUID, URL и источники фиксируются в `skipped_pages`.
- По умолчанию пропуск отключён: экспорт Markdown & CSV не позволяет достоверно определить архивность. Ссылки без Notion ID продолжают получать заглушки.
- Переключатель добавлен в нативное окно, для CLI — `--skip-missing`. Тесты и документация адаптированы к новой структуре.
- Готовый архив v0.4.0 — предыдущая версия; с 0.5.1 публикация требует успешных CI-проверок.
